# 📊 Sales Performance Analytics Dashboard | Power BI

## 📌 Overview

This project is an interactive **Sales Performance Analytics Dashboard** developed using **Power BI** to monitor and analyze business performance across sales, profit, products, and countries.

The dashboard transforms raw sales data into meaningful business insights through interactive visualizations, KPI tracking, and trend analysis.

It enables stakeholders to:
- Monitor revenue and profitability
- Analyze sales performance over time
- Identify top-performing products
- Compare country-level sales metrics
- Track Year-over-Year (YoY) business growth

Sales Performance Analytics Dashboard | Power BI
Overview

This project is an interactive Power BI Sales Analytics Dashboard built to monitor business performance across revenue, profit, products, countries, and yearly sales trends.

The dashboard provides executive level insights into:
• Revenue growth
• Profitability trends
• Product performance
• Country level sales distribution
• Order quantity analysis
• Year over Year (YoY) business changes

The goal of the project is to transform raw sales data into actionable business intelligence using Power BI data modeling, DAX measures, and interactive visualizations.

Key Features
Executive KPI Monitoring

The dashboard tracks important business metrics including:
• Total Revenue
• Total Profit
• Cost of Goods Sold (COGS)
• Profit Margin %
• Total Products Sold
• Unsold Products
• Total Order Quantity

Trend Analysis

Interactive visualizations help analyze:
• Profit trend by year
• Profit margin by month
• Order quantity by country
• Profit and margin performance over time

Geographic Insights

Country level filters allow users to compare performance across:
• United States
• Canada
• Australia
• France
• Germany
• United Kingdom

Product Performance Analysis

The dashboard identifies:
• Top selling products
• High performing categories
• Revenue generating items

Interactive Filtering

Users can dynamically filter the report using:
• Year slicers
• Country slicers
• Cross filtering visuals
